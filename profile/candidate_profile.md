## Proyectos relevantes

### Batchpix

Motor de procesamiento de imágenes con core en C++ compilado a WebAssembly, interfaz web y backend en Node.js/PostgreSQL. Incluye pipelines configurables, filtros implementados desde cero, multithreading, tests con Catch2, CI/CD y autenticación OAuth.

### JobBud

Herramienta en Python para automatizar búsqueda laboral mediante obtención, normalización, filtrado, deduplicación y evaluación de ofertas. Combina procesamiento determinista con agentes LLM especializados.

La arquitectura, división de responsabilidades y decisiones generales de diseño son propias. Parte de la implementación se desarrolla utilizando asistencia de LLMs.

### Sistemas

Experiencia académica desarrollando un kernel educativo x86 de 32 bits con paginación, interrupciones, scheduler y syscalls.
